# Escape Mode – link in bio

Static Hebrew RTL link page for [@escape.mode.go](https://www.instagram.com/escape.mode.go/), based on [LittleLink](https://github.com/sethcottle/littlelink) (MIT).

## Edit a deal

All live content lives in `deals.js` (`window.ESCAPE_MODE_DEALS`). Swap the `active` object when the next destination goes live. Leave `price` as `null` unless the price was verified that session.

## Swap the avatar

Replace `images/avatar.jpg` with Zibo’s real face photo (square JPG). No other changes needed.

## Host on GitHub Pages

Push this folder to a repo under `ziv101010` and enable Pages on the root (or `/docs`). Do not publish until Zibo says OK.
